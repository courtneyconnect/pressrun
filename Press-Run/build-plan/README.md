# Press Run · Technical build plan (M1)

The build plan is a Claude Docs doc so it can be edited and commented on:
**https://claude.ai/artifact/TyNQ9MsuUGzFaS7RRq1w6c**

To keep a file copy, export it from the doc's menu (Markdown, Word or PDF) and save it in this folder.

What's in it:

1. Recommended stack (Bun + Hono + Postgres/Prisma + pg-boss on Railway, R2 for files, Claude API for reading replies, Satori cards, ffmpeg clips, Vercel landing site)
2. Sendblue vs Linq, with a recommendation (Linq, after a reaction test)
3. Press stop database tables
4. How cards and clips get made
5. How a run request becomes numbered options, and how replies and reactions are read
6. Passing messages between both sides
7. What the first working version covers, and the build order
8. Decisions for Courtney
9. Sources
