# Press-Run

Planning files for Press Run. Copy this folder to `~/Desktop/CLAUDE/Press-Run/` to keep it with the rest.

| Folder | What's inside |
| --- | --- |
| `scripts/` | Booker and press stop onboarding text scripts (M1) |
| `mockup/` | Source of the clickable iMessage mockup. Live version: https://claude.ai/artifact/TgKNYFjdmLcrejBQuX7zvz |
| `build-plan/` | Pointer to the technical build plan doc, plus its diagrams |
| `content-log/` | Screenshots for build-in-public posts, one folder per session |
| `process-notes/` | Steps to repeat this process for the next idea (Stream Team) |

The `backend/` and `mobile/` folders at the top of this repo are the old Vibe Code app export, kept for reference.
