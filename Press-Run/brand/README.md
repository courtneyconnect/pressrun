# Press Run brand files

- `press-run-logo-black-1024.png`: the walking camera-head logo on a pure black backdrop, with the red crosswalk glow kept. 1024 × 1024. Made from the old Vibe Code app icon (`mobile/assets/images/icon.png`).
- `logo-before-after.png`: the original gray backdrop (left) next to the black version (right).

Brand colors: black `#0A0A0B`, charcoal `#19191B`, red `#F0413A`. The character is still its original slate gray (about `#48525A`). Whether to lighten it on black is still open.

Apple Messages for Business needs the logo with 10% inset padding, so it will need a padded export later (M5).

## Brand one-sheet

- `press-run-brand-one-sheet.png`: logo, colors, type, shapes, voice, words, and do/don't on one page.
- `press-run-brand-one-sheet.html`: the source. Open it in a browser to edit, then screenshot again.

Fonts: Big Shoulders Display 900 (headings, cards, Run Sheet), Inter Tight Bold (website line, stand-in for Neue Haas Grotesk Display 75 Bold), Figtree 400/600 (body), IBM Plex Mono 600 (labels and data). Also on the one-sheet: slate `#48525A` (the character), off-white `#F4F4F5`, gray `#9A9AA2`, line `#2E2E33`, and iMessage blue `#0A84FF` (Text Press Run button only).
